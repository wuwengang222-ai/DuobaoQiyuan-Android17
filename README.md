# 夺宝奇缘1+2 Android 17 移植项目

本仓库用于开发一款 Android 17 应用，通过 [VMRP](https://github.com/vmrp/vmrp) 运行原始 MRP 游戏，尝试在第一部剧情结束后衔接第二部。

**当前状态：开发中。尚未构建或通过 Android 17 模拟器测试。**

## 原版游戏版权
原版《夺宝奇缘1》和《夺宝奇缘2》的 MRP 文件不属于此项目的开源源码。公开仓库**不要上传**未经许可的游戏文件或包含游戏文件的 APK。

## 验收要求
1. 两部游戏可以在 Android 17 模拟器实际启动和操作；
2. 存档、退出、重进运行正常；
3. 第一部完整通关时识别真实结束事件；
4. 通关后安全切换第二部；
5. 提供经测试的安装包；如公开分发，须具备相应游戏版权授权。

原始模拟器 [VMRP](https://github.com/vmrp/vmrp) 按 GPL-3.0 授权；集成时需遵守许可要求。
